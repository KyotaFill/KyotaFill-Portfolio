# KyotaFill Portfolio

Personal portfolio for Trần Trung Kiên (`KyotaFill`), focused on AI/ML, computer vision, full-stack products, and connected systems.

## Preview locally

```bash
python3 -m http.server 4175
```

Then open <http://localhost:4175>.

The site is plain HTML, CSS, and JavaScript, so it can be deployed to GitHub Pages, Cloudflare Pages, Netlify, or any static host.

## Content

- Personal profile and current focus
- Six selected GitHub projects
- Technical capabilities and toolchain
- Responsive desktop and mobile layouts
- Accessible navigation, reduced-motion support, and basic SEO metadata
- Interactive Live2D Asuna with all 49 original outfits, randomized on reload
- Hover, click, copy, expression, speech-bubble, and pointer-follow reactions
- All 22 original anime banners, shuffled across cards on reload
